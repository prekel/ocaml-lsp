# Функции VS Code: эта ветка и upstream для OCaml 4.14

Срез на 27 октября 2026 года. Upstream — **OCaml-LSP `1.21.0-4.14`**, коммит [`4fb73155`](https://github.com/ocaml/ocaml-lsp/commit/4fb73155251d669f21bcfef14ba2a1890869a11b). Эта ветка — **`fix/4.14-code-actions`**, коммит [`e8fa0a2e`](https://github.com/prekel/ocaml-lsp/commit/e8fa0a2e6c6f3bc88d3f3c5bdb431bb0f47104e8), 38 коммитов поверх базы. Сравнение именно с релизом для 4.14, а не с современным `master`: часть исправлений перенесена из более новых версий upstream.

Под «в VS Code» имеется в виду существующее расширение OCaml Platform с сервером из этой ветки. Изменений кода расширения для перечисленных возможностей не требуется. Команды приведены по именам; сочетания клавиш зависят от системы и раскладки. Сравнение сверено с исходниками, документацией и регрессионными тестами; это не отчёт о ручном прогоне интерфейса VS Code.

Для первой установки и последующих обновлений выполните одну и ту же команду в opam switch проекта с **OCaml 4.14**:

```bash
opam pin add -y ocaml-lsp-server.1.21.0-4.14 'git+https://github.com/prekel/ocaml-lsp.git#fix/4.14-code-actions'
```

Команда устанавливает сервер, а при повторном запуске подтягивает изменения ветки и пересобирает пакет при необходимости. Версия `1.21.0-4.14` согласует зависимости `lsp` и `jsonrpc`. Подробнее о pin — в [документации opam](https://opam.ocaml.org/doc/man/opam-pin.html).

В VS Code выберите этот switch через **OCaml: Select a Sandbox**. После установки или обновления перезапустите language server.

Уже существовали и не были добавлены этой веткой: обычное completion, outline/document symbols, folding, подсветка OCaml semantic tokens, Format Document, базовые hover, hints и CodeLens, destruct/construct, обновление сигнатуры и прочие неуказанные Code Actions. Их наличие само по себе не является отличием от upstream.

По-прежнему отсутствуют добавленные возможности project-wide Rename, динамический анализ callback-вызовов и object dispatch, поиск всех структурных реализаций сигнатуры, автоматический запуск `dune build` для навигации и задаваемые сервером цвета/стили подчёркивания.
